# duforn Sanity Studio

Editorial studio for [duforn](https://namanprat.com). Project `dj9l9mvw`, dataset `production`.

```sh
npm install
npm run dev
```

The site fetches published documents at build time and falls back to the YAML collections in `src/content/` when this dataset is empty.

Studio pages: Work, Archive, Homepage (eyebrow, FAQ, process), Footer, About, Marquee.
